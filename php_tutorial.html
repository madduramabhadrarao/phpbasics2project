What is PHP?

Understanding the big picture before writing a single line

🐘 PHP — Hypertext Preprocessor Server-Side

PHP is a scripting language that runs on the web server. When a user opens a webpage, PHP processes the code and sends plain HTML back to the browser.

👤 Browser
Request
→
🖥️ Web Server
Apache/Nginx
→
🐘 PHP
Processes
→
🗄️ MySQL
If needed
→
📄 HTML
Response

✅ What PHP Can Do

  • Create dynamic web pages
  • Handle HTML forms
  • Connect to databases (MySQL)
  • Manage sessions & cookies
  • Read/write files
  • Send emails

🛠️ Tools You Need

  • XAMPP — local server (Apache + MySQL + PHP)
  • VS Code — code editor
  • Browser — Chrome / Firefox
  • Files go in htdocs folder
  • Open via localhost/yourfolder
💡
Teaching Tip: Install XAMPP first. Show students: Start Apache → Start MySQL → Open browser → type localhost. This "hello world" moment builds confidence!

Basic PHP Syntax

How to write your first PHP code

🏷️ PHP Tags Required

All PHP code must be wrapped inside PHP tags. The server looks for these tags to know where PHP starts and ends.

<?php
    // Your PHP code goes here
    echo "Hello, Students!";
?>

📢 echo vs print

<?php
echo "Hello World";
print "Hello World";

// echo is faster (preferred)
// Both do the same thing
?>

💬 Comments

<?php
// Single line comment

/* Multi-line
   comment */

# Also single line
?>

📄 PHP Inside HTML

PHP and HTML can be mixed freely. PHP executes on the server, HTML is sent to the browser.

<!DOCTYPE html>
<html>
<body>
    <h1><?php echo "Welcome to PHP!"; ?></h1>
    <p>Today is: <?php echo date("d-m-Y"); ?></p>
</body>
</html>
Browser Output:

Welcome to PHP!

Today is: 17-03-2026

⚠️
Common Mistake: Forgetting the semicolon ; at the end of each statement. Every PHP statement must end with ;

Variables

Storing and using data in PHP

📦 What is a Variable?

A variable is a container that stores data. In PHP, all variables start with $.

<?php
$name  = "Ram";       // String
$age   = 20;         // Integer
$marks = 85.5;       // Float
$pass  = true;        // Boolean

echo "Name: " . $name;   // . joins strings
echo "Age: "  . $age;
?>

📏 Variable Rules

RuleExampleValid?
Must start with $$name✅
Letters or underscore after $$_name✅
Case-sensitive$Name ≠ $name⚠️
No spaces in name$my name❌
No starting with number$1name❌

🔗 String Concatenation

<?php
$first = "Ram";
$last  = "Kumar";

// Using dot (.)
echo $first . " " . $last;
// Output: Ram Kumar

// Using double quotes
echo "$first $last";
?>

🔄 Variable Variables

<?php
// Shorthand assignment
$x  = 10;
$x += 5;   // $x = 15
$x -= 3;   // $x = 12
$x .= "!";  // $x = "12!"
echo $x;
?>
📝
Note: PHP is loosely typed — you don't need to declare the type. PHP figures it out automatically: $x = 5 is an integer, $x = "5" is a string.

Data Types

Different kinds of values PHP can store

🗂️ All PHP Data Types

<?php
$name    = "Ram";          // String
$age     = 20;             // Integer
$marks   = 85.5;           // Float (decimal)
$isPass  = true;            // Boolean

// Check type with gettype()

🔠 String Functions Useful

<?php
$s = "Hello World";

echo strlen($s);       // 11
echo strtoupper($s);   // HELLO WORLD
echo strtolower($s);   // hello world
echo str_replace(
  "World", "PHP", $s
);  // Hello PHP
?>

🔢 Number Functions Math

<?php
echo abs(-10);      // 10
echo ceil(4.3);     // 5
echo floor(4.9);    // 4
echo round(4.5);    // 5
echo pow(2, 3);      // 8
echo sqrt(16);      // 4
echo rand(1, 100);  // random
?>

Type Casting: You can convert between types: (int)"42" → 42, (string)100 → "100", (float)"3.14" → 3.14

Operators

Performing operations on values and variables

➕ Arithmetic Operators

<?php
$a = 10;
$b = 3;

echo $a + $b;  // 13
echo $a - $b;  // 7
echo $a * $b;  // 30
echo $a / $b;  // 3.33
echo $a % $b;  // 1 (remainder)
echo $a ** $b; // 1000 (power)
?>

🔍 Comparison Operators

<?php
$a = 10;  $b = 5;

$a == $b   // Equal (false)
$a != $b   // Not equal (true)
$a > $b    // Greater (true)
$a < $b    // Less (false)
$a >= $b   // Greater/equal
$a === $b  // Identical (type+value)
?>

🧠 Logical Operators

<?php
$x = true;
$y = false;

$x && $y  // AND → false
$x || $y  // OR  → true
!$x        // NOT → false
?>

⚡ Increment/Decrement

<?php
$i = 5;
$i++;   // $i becomes 6
$i--;   // $i becomes 5
++$i;   // pre-increment
--$i;   // pre-decrement
echo $i;  // 5
?>
⚠️
== vs ===: == checks value only ("5" == 5 is true), === checks value AND type ("5" === 5 is false). Use === for strict checking!
5

Control Structures

Making decisions in your PHP code

🔀 if / else if / else

<?php
$marks = 72;

if ($marks >= 90) {
    echo "Grade: A+";
} elseif ($marks >= 75) {
    echo "Grade: A";
} elseif ($marks >= 60) {
    echo "Grade: B";   // ← This runs
} elseif ($marks >= 50) {
    echo "Grade: C";
} else {
    echo "Fail";
}
?>

🔁 switch Statement

Use switch when you have many possible values for one variable. Cleaner than many if-elseif chains.

<?php
$day = 3;

switch ($day) {
    case 1: echo "Monday";    break;
    case 2: echo "Tuesday";   break;
    case 3: echo "Wednesday"; break; // ← runs
    case 4: echo "Thursday";  break;
    case 5: echo "Friday";    break;
    default: echo "Weekend!";
}
?>

❓ Ternary Operator Shortcut

<?php
$marks = 55;

// Long way:
if ($marks >= 50) { $result = "Pass"; }
else { $result = "Fail"; }

// Ternary shortcut:
$result = ($marks >= 50) ? "Pass" : "Fail";

echo $result; // Pass
?>
⚠️
Don't forget break in switch! Without it, PHP will "fall through" and execute the next case too.

Loops

Repeating code multiple times efficiently

🔁 for Loop

<?php
// Print 1 to 5
for ($i=1; $i<=5; $i++) {
    echo $i . "<br>";
}

// Countdown
for ($i=5; $i>=1; $i--) {
    echo $i . " ";
}
?>

🔄 while Loop

<?php
$i = 1;

while ($i <= 5) {
    echo $i . "<br>";
    $i++;
}

// do-while (runs at least once)
do {
    echo $i;
    $i++;
} while ($i <= 3);
?>

🎯 Practical Loop Examples

<?php
// Multiplication Table for 5
for ($i=1; $i<=10; $i++) {
    echo "5 x $i = " . (5*$i) . "<br>";
}

// Sum of 1 to 100
$sum = 0;
for ($i=1; $i<=100; $i++) {
    $sum += $i;
}
echo "Sum = " . $sum; // 5050

// break and continue
for ($i=1; $i<=10; $i++) {
    if ($i == 5) continue; // skip 5
    if ($i == 8) break;    // stop at 8
    echo $i . " "; // 1 2 3 4 6 7
}
?>

Arrays

Storing multiple values in one variable

📋 Indexed Array

<?php
$students = ["Ram", "Sita", "Ravi", "Priya"];
//             [0]     [1]     [2]     [3]

echo $students[0];  // Ram
echo $students[2];  // Ravi

// Loop through
foreach ($students as $name) {
    echo $name . "<br>";
}

echo count($students);  // 4
?>

🗂️ Associative Array (Key → Value)

<?php
$student = [
    "name"   => "Ram Kumar",
    "roll"   => "CS101",
    "marks"  => 85,
    "branch" => "CSE"
];

echo $student["name"];    // Ram Kumar
echo $student["marks"];   // 85

foreach ($student as $key => $value) {
    echo "$key: $value <br>";
}
?>

🔧 Useful Array Functions

<?php
$nums = [3, 1, 4, 1, 5, 9];

sort($nums);           // [1,1,3,4,5,9]
array_push($nums, 2); // add to end
array_pop($nums);     // remove last
array_merge($a, $b);  // combine arrays
in_array(5, $nums);   // true/false
array_unique($nums);  // remove duplicates
?>

Functions

Reusable blocks of code

🔧 Basic Function

<?php
// Define the function
function greet($name) {
    return "Hello, " . $name . "!";
}

// Call the function
echo greet("Ram");    // Hello, Ram!
echo greet("Sita");   // Hello, Sita!
?>

⚙️ Default Parameters

<?php
function power($base, $exp=2) {
    return pow($base, $exp);
}

echo power(3);      // 9 (3²)
echo power(3, 3);   // 27 (3³)
?>

🔢 Return Values

<?php
function calculate($a, $b) {
    return [
        "sum"  => $a + $b,
        "diff" => $a - $b,
        "prod" => $a * $b
    ];
}

$r = calculate(10, 5);
echo $r["sum"];  // 15
?>

🌍 Variable Scope

<?php
$name = "Global Ram";

function test() {
    // $name not accessible here by default!
    global $name;  // use global keyword
    echo $name;     // Now works
}

test(); // Global Ram
?>

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {

    // Get & sanitize input
    $name  = htmlspecialchars($_POST["name"]);
    $email = htmlspecialchars($_POST["email"]);
    $age   = intval($_POST["age"]);

    // Validate
    if (empty($name)) {

    } else {

?>

MySQL Database

Connecting PHP to a database for persistent storage

🔌 Connecting to MySQL

<?php
// db_config.php — include this in every file
$host = "localhost";
$user = "root";
$pass = "";
$db   = "student_db";

$conn = mysqli_connect($host, $user, $pass, $db);

if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
}
// Connection successful!
?>

📋 CRUD Operations

<?php
// CREATE — Insert
$sql = "INSERT INTO students (name, email, marks)
        VALUES ('Ram', 'ram@email.com', 85)";
mysqli_query($conn, $sql);

// READ — Select All
$sql = "SELECT * FROM students";
$result = mysqli_query($conn, $sql);
while ($row = mysqli_fetch_assoc($result)) {
    echo $row["name"] . " - " . $row["marks"];
}

// UPDATE
$sql = "UPDATE students SET marks=90 WHERE id=1";
mysqli_query($conn, $sql);

// DELETE
$sql = "DELETE FROM students WHERE id=1";
mysqli_query($conn, $sql);
?>

🛡️ Prepared Statements Secure

Always use prepared statements to prevent SQL Injection attacks!

<?php
// Safe way to insert user data
$stmt = mysqli_prepare($conn,
    "INSERT INTO students (name, email) VALUES (?, ?)"
);

mysqli_stmt_bind_param($stmt, "ss",
    $name, $email  // "ss" = string, string
);

$name  = $_POST["name"];
$email = $_POST["email"];

mysqli_stmt_execute($stmt);
echo "Student added safely!";
?>

Sessions & Cookies

Remembering users across pages

🔐 Sessions

<?php
// ALWAYS at the top!
session_start();

// Store data
$_SESSION["user"]  = "Ram";
$_SESSION["role"]  = "student";
$_SESSION["loggedIn"] = true;

// Read data (another page)
echo $_SESSION["user"];

// Destroy session (logout)
session_destroy();
?>

🍪 Cookies

<?php
// Set cookie (1 hour)
setcookie(
    "username",
    "Ram",
    time() + 3600
);

// Read cookie
echo $_COOKIE["username"];

// Delete cookie
setcookie("username", "", time()-1);
?>

🔒 Login System Pattern

<?php
session_start();

// Protect a page — redirect if not logged in
if (!isset($_SESSION["loggedIn"])) {
    header("Location: login.php");
    exit();
}

// Logout
if (isset($_GET["logout"])) {
    session_destroy();
    header("Location: login.php");
    exit();
}
?>
📝
Session vs Cookie: Sessions are stored on the server (more secure). Cookies are stored on the user's browser (can be seen/edited). Use sessions for login info, cookies for preferences like "remember me".

require 'db_config.php';

        $_SESSION["loggedIn"]  = true;
        $_SESSION["username"] = $user;
        header("Location: index.php");
    } else {
        $error = "Invalid username or password!";
    }
}
?>

<html><head><title>Login</title></head>
<body>

    <input type="password" name="password" placeholder="Password" required><br>

  </form>
</body></html>
